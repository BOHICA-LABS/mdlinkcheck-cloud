# S-3.04: Anchor Resolution — Same-File, Cross-File, and Ignored-Source Lookups

> **One-per-file:** This story is `S-3.04` in EPIC-03 — Anchor Checking (`E-3`).
> Implements `anchor_resolver.rs` (pure-core). Covers three anchor resolution scenarios:
> same-file anchor-only links (`#fragment`), cross-file anchor links (`path.md#fragment`),
> and cross-file anchor links into `--ignore`'d source files. Discharges D-165: the
> fragment is percent-decoded BEFORE anchor-table lookup (BC-2.08.001 invariant 3).

### AC-001 (traces to BC-2.08.001 postcondition 1 — D-165 discharge)
For a link whose destination starts with `#`, the fragment is extracted as
`destination.strip_prefix('#')`. That fragment string is then **percent-decoded** (using
`percent_encoding::percent_decode_str`) before the anchor-table lookup. No case-folding is
applied at any point (DI-003, CAP-008).
- **Test:** `test_BC_2_08_001_fragment_percent_decoded_before_lookup()`

### AC-002 (traces to BC-2.08.001 postcondition 2)
The decoded fragment is looked up in the **source file's own** anchor table (not any other
file's table). `anchor_resolver::resolve` takes `fragment: &str` and `table: &AnchorTable`
where `table` is the source file's own AnchorTable.
- **Test:** `test_BC_2_08_001_lookup_in_source_file_table()`

### AC-003 (traces to BC-2.08.001 postcondition 3)
If the decoded fragment is found in the anchor table: verdict is `clean`.
- **Test:** `test_BC_2_08_001_found_fragment_yields_clean()`

### AC-004 (traces to BC-2.08.001 postcondition 4)
If the decoded fragment is NOT found in the anchor table: verdict is `broken(anchor-not-found)`.
Case mismatch counts as not-found: `[x](#Setup)` where the anchor table contains `"setup"`
yields `broken(anchor-not-found)` — the lookup is verbatim slug comparison, case-sensitive.
- **Test:** `test_BC_2_08_001_missing_fragment_yields_anchor_not_found()`
- **Test:** `test_BC_2_08_001_case_mismatch_yields_anchor_not_found()`

### AC-005 (traces to BC-2.08.001 postcondition 5)
An empty anchor `[x](#)` (bare hash, empty fragment after stripping `#`) yields `clean`.
This is the "top of page" convention; an empty fragment string always resolves clean.
- **Test:** `test_BC_2_08_001_empty_anchor_yields_clean()`

### AC-006 (traces to BC-2.08.001 invariant 3 — D-165 decode-ordering integration test)
Percent-encoded fragment is decoded before lookup: a link `[x](#caf%C3%A9)` in a file that
has heading `## Café` (slug `"café"`) resolves clean because `%C3%A9` decodes to `é`, giving
decoded fragment `"café"` which matches the anchor table entry. This is the VP-004 P6 integration
test (`vp004_fragment_percent_decode_before_anchor_lookup`).
- **Test:** `test_BC_2_08_001_percent_encoded_fragment_decoded_before_lookup_vp004_p6()`

### AC-007 (traces to BC-2.08.001 invariant 4)
Invalid percent sequences (e.g., `#caf%GG`) are passed through undecoded. The raw fragment
`"caf%GG"` is used for the anchor-table lookup. If no anchor key matches, verdict is
`broken(anchor-not-found)`. `malformed-url` is NOT emitted — that error code is scoped to
external URLs only (error-taxonomy.md §2.3, 13-code closed set).
- **Test:** `test_BC_2_08_001_invalid_percent_sequence_passed_through_undecoded()`

### AC-008 (traces to BC-2.08.002 postcondition 2)
Cross-file link: if the resolved path does not exist as a file or directory, verdict is
`broken(file-not-found)`. File-not-found takes precedence over anchor-not-found — the file
must exist before any anchor lookup occurs.
- **Test:** `test_BC_2_08_002_missing_file_yields_file_not_found()`

### AC-009 (traces to BC-2.08.002 postcondition 5)
Cross-file `.md` link: resolved path exists as a `.md` file but the fragment is NOT in its
anchor table: verdict is `broken(anchor-not-found)`.
- **Test:** `test_BC_2_08_002_md_file_missing_fragment_yields_anchor_not_found()`

### AC-010 (traces to BC-2.08.002 postcondition 6)
Cross-file `.md` link: resolved path exists as a `.md` file and the fragment IS in its anchor
table: verdict is `clean`.
- **Test:** `test_BC_2_08_002_md_file_found_fragment_yields_clean()`

### AC-011 (traces to BC-2.08.002 postcondition 7)
Empty fragment `path.md#` (bare hash after path component): verdict is `clean`, same as
BC-2.08.001's empty anchor convention.
- **Test:** `test_BC_2_08_002_empty_fragment_after_path_yields_clean()`

### AC-012 (traces to BC-2.08.002 invariant 3)
Out-of-scan-set `.md` files excluded via any of the four DI-006 mechanisms (`--ignore`,
`.gitignore`, dot-directory, outside scan root) are valid anchor targets. Their anchor tables
are built by Pass 1 (for `--ignore`'d files) or Pass 1.5 (for the other three cases) before
Pass 2 runs, ensuring cross-file anchor resolution into them works correctly.
- **Test:** `test_BC_2_08_002_out_of_scan_set_md_target_valid_anchor_target()`

### AC-013 (traces to BC-2.08.002 invariant 4)
`anchor_resolver.rs` is called ONLY for `.md` file targets with a fragment. Non-`.md` file
targets are handled by `path_resolver.rs` (existence check only; `anchor_resolver` is never
called). Directory targets are handled by `path_resolver.rs` (BC-2.07.005). The integration
test must assert that a link `[x](notes.txt#section)` where `notes.txt` exists yields `clean`
without ever calling `anchor_resolver::resolve`.
- **Test:** `test_BC_2_08_002_non_md_target_not_routed_to_anchor_resolver()`

### AC-014 (traces to BC-2.08.004 postcondition 1)
When `b.md` is excluded as a link source by `--ignore b.md`, its anchor table is still built
during Pass 1 (DI-006). The `--ignore` flag applies to link source traversal only; it never
prevents anchor table construction for the excluded file.
- **Test:** `test_BC_2_08_004_ignored_source_anchor_table_built_in_pass1()`

### AC-015 (traces to BC-2.08.004 postcondition 3)
`a.md` has `[x](b.md#setup)`; `b.md` is `--ignore`'d as a source but exists and has `## Setup`:
verdict is `clean`.
- **Test:** `test_BC_2_08_004_anchor_link_into_ignored_source_with_heading_clean()`

### AC-016 (traces to BC-2.08.004 postcondition 4)
`a.md` has `[x](b.md#missing)`; `b.md` is `--ignore`'d as a source but has no `## Missing`:
verdict is `broken(anchor-not-found)`.
- **Test:** `test_BC_2_08_004_anchor_link_into_ignored_source_missing_heading_broken()`

### AC-017 (traces to BC-2.08.004 invariant 1)
`--ignore` applies to link source traversal ONLY. It NEVER affects anchor table construction.
The DI-006 invariant holds: anchor tables are built for ALL traversed files.
- **Test:** `test_BC_2_08_004_ignore_does_not_suppress_anchor_table_construction()`

|-------|--------------|---------------------|-------------------|

## Architecture Compliance Rules (MANDATORY)

| Rule | Source | Enforcement |
|------|--------|-------------|
| `anchor_resolver.rs` MUST be in `mdlinkcheck-core` (pure-core library crate) | ADR-001, ADR-002 | Compile check |
